# Starter

A basic widget pack for testing and development.

## Widgets

### `wallpaper`

Coniston photo filling every monitor behind application windows. Uses the local
`resources/coniston.jpg` image and passes desktop clicks through the native
window. This does not modify Windows wallpaper policies.

### `vanilla`

Plain and simple.

### `with-glazewm`

For use with [GlazeWM](https://github.com/glzr-io/glazewm).

### `with-komorebi`

For use with [Komorebi](https://github.com/LGUG2Z/komorebi).
